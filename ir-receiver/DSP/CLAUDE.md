# IR Remote Receiver — DSP pipeline

Analog IR remote receiver (EE side project). Hardware is designed, simulated in
LTspice, and laid out in KiCad (2-layer, 0 DRC errors, not yet ordered).
This repo holds the Python DSP pipeline and its fixed-point C port (`firmware/`).
Write-up of the 2026-09-25 simulation study: `RESULTS.md`.

## Hardware (5 V single supply)
- VDC = 2.5 V: 10k/10k divider + 10 µF, buffered by LM324 section C; section D spare (follower).
- D1 BPW34: cathode to 5 V, anode to TIA input (reverse-biased).
- TIA (U1A): Rf = 330k, Cf = 4.7 pF (pole ≈ 103 kHz).
- MFB bandpass (U1B): R3 = 8.66k, R4 = 1.07k (to VDC), R5 = 97.6k, C1 = C2 = 360 pF C0G; gain ≈ 5.6, Q ≈ 5, ~38 kHz.
- Comparator U2 (LM311/LT1011): RV1 threshold ~3.0 V, R10 = 10k / R11 = 330k hysteresis,
  open-collector, 4.7k pull-up to 3.3 V.
- J1 (1×4): VDD, +3V3, GND, OUT → ESP32. Planned: add "ANA" pin (TIA out → 1k).

## Files
- `ir_dsp.py` — full float pipeline (single module); the reference for everything else.
- `firmware/` — fixed-point C port, integer only, streaming:
  - `goertzel.c/.h`: `gz_push()` one ADC code in, amplitude (Q3 ADC codes) every 32 samples.
  - `iq.c/.h`: `iq_push()` same interface; DC blocker → 38 kHz mixer (250-entry table) →
    CIC3 ÷8 → 48-tap FIR ÷4 → |I+jQ|. ~70 dB rejection at 45 kHz (Goertzel ~25 dB);
    all multiplies 16×16→32 bit.
  - `ir_rx.c/.h`: `ir_rx_init(rx, IR_DET_GOERTZEL | IR_DET_IQ)`, `ir_rx_push()` ADC code in,
    NEC frames out (detector → shared slicer → runs → NEC).
  - `gz_tables.h`: GENERATED by `test_goertzel_fixed.py` (Goertzel window, I/Q LO + FIR taps,
    slicer constants) — don't hand-edit; change the design constants in that script.
  - `gz_run.c`, `ir_run.c`: host test drivers, `-iq` selects I/Q (`*.exe` are build outputs).
- `test_goertzel_fixed.py` — table generator + build; checks Goertzel bit-exact vs an integer model and vs float.
- `test_iq_fixed.py` — I/Q detector bit-exact vs integer model, vs a float model of the same
  structure, and decodes (incl. `../sim/exports/Draft5_servo_allnoises.txt`, where Goertzel fails).
- `test_ir_rx.py` — C receiver end to end vs the Python pipeline (frames + slicer bit agreement).
- `sweep_fixed.py` — decode-rate chart `decode_rate.png` (data in `out/decode_rate.json`).
- `demo.py` — one-figure pipeline demo `demo.png` (ADC codes → C envelope + threshold →
  slicer bits with decoded bytes); `python demo.py <export> [--detector iq] --out x.png`.
  `demo_goertzel_allnoises.png` / `demo_iq_allnoises.png` are the side-by-side failure/success pair.
- `nec_0x04_0x08.pwl` (100 nA), `nec_20nA.pwl` — NEC photocurrent stimuli for LTspice.
- LTspice working schematics live in `../sim/drafts/` (Draft3_nec, Draft4_gain*, Draft5_servo*; PWL paths are
  relative, `..\..\DSP\*.pwl`); their waveform exports live in `../sim/exports/` (gitignored, 6-48 MB each).

## Commands
```
python ir_dsp.py                          # synthetic demo + plots (out/)
python ir_dsp.py --isig 30e-9             # weaker signal
python ir_dsp.py --sweep                  # sensitivity sweep, all 3 demodulators
python ir_dsp.py --write-pwl nec.pwl      # LTspice stimulus
python ir_dsp.py --ltspice run.txt --node "V(tia)" --out-node "V(out)"
python test_goertzel_fixed.py             # build C + Goertzel checks (expects PASS)
python test_ir_rx.py                      # C receiver end to end (expects PASS)
python test_iq_fixed.py                   # C I/Q detector (expects PASS)
python sweep_fixed.py                     # decode-rate chart, ~20 s
python demo.py                            # pipeline demo figure (demo.png)
```
C builds use MSYS2 GCC at `C:/msys64/ucrt64/bin/gcc.exe` (installed 2026-09-25; override with `GCC`).
LTspice batch runs of a 20 ms window take ~10 s; a full 140 ms run with the comparator
toggling takes minutes — run one at a time.
LTspice setup: `I1 +5V TIA_IN PWL file=nec.pwl` in parallel with the BPW34 model,
`.options plotwinsize=0`, `.tran 0 140m 0 200n`, then File → Export data as text.

## Pipeline (current state — working)
1. Source: synthetic (TIA model simulated at 4 MHz, sampled at 500 kSPS with no
   anti-alias filter, 12-bit ADC) or LTspice export resampled to a uniform grid.
2. Spectrum: Welch PSD + spectrogram.
3. Demodulators: FIR bandpass 34–42 kHz / 301 taps (offline reference only);
   Goertzel N=128 Hann, hop 32; I/Q mixer + 3 kHz 255-tap FIR lowpass.
4. Adaptive slicer: floor (updated only while output low) + fast-attack/slow-decay
   peak, hysteresis 0.5/0.35, SNR gate 4×.
5. Run-length + glitch merge (<150 µs) → NEC decoder (standard/extended addr, repeat codes).

## Results so far (details and numbers: `RESULTS.md`)
- DSP decodes the LTspice NEC frame at 100 nA and 20 nA (all three demodulators).
- Sweep (10 trials/point, `sweep_fixed.py`): all methods 100% from 20 nA clean; with a
  100 nA 45 kHz interferer, I/Q (C and float) and FIR from 20 nA, Goertzel from 30 nA.
- `../sim/exports/Draft5_servo_allnoises.txt` (exported without an extension, renamed; 20 nA remote + 1 µA + 120 Hz flicker +
  100 nA @45 kHz + white noise, full 140 ms): Goertzel (C and float) decodes NOTHING —
  45 kHz leakage lifts the floor to ~2 codes, peak/floor 3.16 < SNR gate 4. I/Q (C) decodes it.
- Goertzel N=64 only gave −4.6 dB at 45 kHz → false triggers; N=128 gives −25 dB.
- Fixed-point C = float: Goertzel bit-exact vs integer model (≤0.16 code vs float),
  slicer 100% bit agreement, identical decoded frames on every test input.
- Original comparator path FAILS at 100 nA (threshold 3.0 V; band-pass only ±97 mV).

## Simulated circuit changes (LTspice only — NOT in KiCad yet)
- Threshold from VDC: R6 1k (to VDC) / R7 22k (to VDD) → VDC + ~110 mV; R11 = 1 MΩ.
- ×10 AC-coupled inverting stage before R10 (C 10n, 10k, 100k; LM324) → comparator
  decodes 100 nA and 20 nA (`../sim/drafts/Draft4_gain*`).
- DC servo: integrator (150k from tia to −, 1 nF feedback, + at VDC) driving U1's +
  input (`servo` net) (`../sim/drafts/Draft5_servo`). It was designed against the REVERSED photocurrent
  (see below). With the real polarity the reference must rise, and the LM324 (input CM /
  output ≤ ~3.5 V) limits centring to ~3 µA (sim: V(tia) 2.11–2.53 V at 2–4 µA). Not needed
  at room-light levels; if kept, redesign it to sink current from the summing node through a
  resistor.
- Better than the ×10 stage: a second MFB band-pass in its place (Ra 4.7k in,
  Rb 1.1k to VDC, Rc 100k feedback, 360p/360p), tuned in simulation with the LM324
  model (textbook values land at 32 kHz). 45 kHz rejection 7.4 → ~15 dB. Tested only in
  scratch netlists, not in the user's .asc files.
- Op-amp count: 4 without the servo (TIA, BP1, VDC buffer, BP2/gain) — fits one LM324;
  5 with a servo → second package.

## Known hardware concerns
- LTSPICE POLARITY BUG: the user's .asc files have the photocurrent source reversed
  (`I1 N002 VDD` pulls current OUT of the TIA input). The PCB has D1 cathode → VDD,
  anode → U1 pin 2 (checked in the .kicad_pcb), so real light pushes current IN and the
  TIA output goes DOWN from ~2.5 V toward 0 V. Model the diode as `I VDD <tia_in> ...`.
  AC/carrier results (comparator, DSP decodes) don't depend on the sign.
- TIA saturates at ~7.5 µA DC photocurrent (2.5 V headroom down to ~0 V / 330k) — the
  original estimate was right. A "3.3 µA / 48% clipped" result recorded on 2026-09-25 came
  from the reversed source and is WRONG for the real board; with the real polarity,
  1 µA + 2 µA±1 µA flicker gives V(tia) 1.08–1.75 V, 0% clipped, all leader edges.
  Direct sunlight / incandescent light on an unfiltered BPW34 can still exceed 7.5 µA.
- Comparator path cannot reject a 100 nA 45 kHz interferer (lamp ballast), even with two
  band-pass stages; tolerance ≈ 40 nA (estimate). The DSP path handles it. An analog AGC /
  adaptive threshold would be the analog fix.
- Comparator OUT is 38 kHz bursts, not an envelope; firmware must gap-fill
  (see `decode_digital_bursts()`).
- LTspice transient has no device noise; noise must be injected (e.g. `bi` source
  `I=5n*white(1e6*time)`).
